# Back Porch Games — Privacy Policy

Public privacy policy page for games published by Back Porch Games
(Block Brunch: Block Puzzle, Big Dill: Idle Pickle Tycoon, and future titles).

- **Live page:** https://dongervais1990-droid.github.io/backporchgames-privacy/
  (after GitHub Pages is enabled — see below)
- **File:** `index.html` — the full policy. Contact: backporchgamesnc@gmail.com

## Enabling GitHub Pages (one-time)

1. Open this repo on GitHub → **Settings** → **Pages**.
2. Under "Build and deployment", Source: **Deploy from a branch**.
3. Branch: **main**, folder: **/(root)** → **Save**.
4. The page goes live at the URL above within a minute or two.

That URL is the one to paste into Google Play Console as the privacy policy
URL for each Back Porch Games app.
